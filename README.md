# Reflex Rush — Vercel-ready edition

This package hosts the static browser game on Vercel, runs `/api/scores` as a Vercel Function, and stores the shared leaderboard in Supabase Postgres. A database is required for scores to persist between deployments and server restarts.

## 1. Create the Supabase database

1. Create a project at https://supabase.com/ (check its current free-plan limits).
2. Open **SQL Editor** and run:

```sql
create table if not exists public.scores (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 18),
  score integer not null check (score >= 0 and score <= 100000),
  created_at timestamptz not null default now()
);

create index if not exists scores_leaderboard_idx
  on public.scores (score desc, created_at asc);

alter table public.scores enable row level security;
```

The API uses the server-only service-role key. Do not add that key to any file under `public/`, commit it to GitHub, or share it. Since the server uses the service key, public table policies are not needed for this API.

## 2. Upload to GitHub

1. Extract this ZIP.
2. Create a GitHub repository, e.g. `reflex-rush-vercel`.
3. Upload the **contents** of this folder, keeping `public/`, `api/`, `package.json`, and `vercel.json` at the repository root.

## 3. Deploy on Vercel

1. Go to https://vercel.com/new and import the repository.
2. Framework preset: **Other**.
3. Root directory: `./`.
4. Let Vercel install dependencies from `package.json`; no build command is required for this static frontend + function project.
5. Deploy.

## 4. Add environment variables

In Vercel, open the project **Settings → Environment Variables** and add these two variables for Production (and Preview if you want preview deployments to use the database):

- `SUPABASE_URL` — from Supabase project settings / API.
- `SUPABASE_SERVICE_ROLE_KEY` — the server-side service-role/secret key from Supabase project API settings. Keep it private.

Save them, then redeploy the project so the function receives the variables.

## 5. Test

- Open your Vercel URL.
- Play a round and allow the score to submit.
- Refresh the page and check the leaderboard.
- Open the URL on another device to confirm the same leaderboard is visible.

## Notes

- The game runs a 30-second round and awards 10 points per hit.
- Player name and personal best use browser local storage; shared leaderboard scores use Supabase.
- This is a fun demo, not a cheat-proof competition: a browser can submit a fabricated score. Do not use it for high-stakes prizes without server-side gameplay validation, rate limiting, and abuse controls.
- Check current Vercel and Supabase free-plan terms/limits before deploying. Free plans and usage allowances can change.
